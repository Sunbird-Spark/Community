# Roadmap

The Sunbird Spark roadmap for the next few quarters focuses on adding further depth on personalisation and AI.&#x20;

The areas of immediate focus are:

* AI pipeline for Content enrichment - Auto-captioning for videos, transcript generation, translation etc.
* Competency Framework Support
* Assessment enhancements and support for international standards such as QTI
* AI-led personalised learning



Other roadmap items cover the following areas, and will be executed in a planned, demand-led fashion so as to factor in needs of adopters and partners:



* Auto-adjustment of the learner flow based on their performance
* Personalisation engine for dynamic content recommendations&#x20;
* AI-based personalised Learning assistant
* AI based generation of assessments - based on a topic/ pdf/ video as an input
* AI powered unstructured learning paths
* AI-led multi-language translation (Real-time AI translation of course content and assessments into regional languages, enabling rapid localization without manual translation workflows)
* AI-assisted Course creation
* iOS consumption app for Spark
